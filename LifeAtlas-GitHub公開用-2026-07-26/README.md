# Life Atlas

更新日：2026年7月26日

収入から税金・保険料・家賃・生活費を差し引き、都市ごとに「毎月いくら残るか」を比較するWebアプリです。

## 現在対応している都市

- 東京、大阪
- バンクーバー、トロント
- ロサンゼルス、ニューヨーク
- ロンドン、パリ、ローマ
- ケレタロ、プエブラ、メリダ、メキシコシティ
- メルボルン

## 現在の主な機能

- 現地通貨と日本円による給与・支出表示
- 日本の所得税、復興特別所得税、住民税、健康保険、介護保険、子ども・子育て支援金、厚生年金、雇用保険の試算
- カナダの連邦・州所得税、CPP（年金）、EI（雇用保険）の試算
- 米国の連邦・州・市所得税、Social Security（年金）、Medicare給与税、雇用主医療保険の加入者負担推定
- 英国の所得税、National Insurance（国民保険）の試算
- フランスの所得税、医療・年金・失業保険等の社会保険の比較用試算
- イタリアのIRPEF（所得税）、INPS（年金保険）、州・市の追加税の比較用試算
- メキシコのISR（所得税）、IMSS（社会保険）の比較用試算
- オーストラリアの所得税、Medicare levy（医療保険税）の試算
- オーストラリアのSuper guarantee（雇用主が積み立てる退職資金）の別表示
- 40歳未満、40〜64歳、65歳以上の年齢区分
- 月間支出、年間貯蓄可能額、家賃負担率、購買力指数、FIREの簡易目安
- 住みやすさ、貯金しやすさ、起業向き、FIRE向き、ノマド向き、家族向き、総合評価の比較
- World Bank（世界銀行）、ECB（欧州中央銀行）、各国の公的資料からの人口・為替データ更新
- データの対象期間、取得時刻、出典リンクの表示
- ダークモード、ライトモード、スマートフォン表示
- 日本語・英語の表示切り替え
- 世帯パターン（単身成人、大人2人、ひとり親＋子ども1人、大人2人＋子ども1人・2人・3人）

## 計算上の重要な前提

税金・保険料は、現地居住者、給与所得のみ、扶養控除なしの比較用試算です。世帯人数と子どもの人数は生活費に反映しますが、扶養控除や児童手当などの税額控除にはまだ反映していません。

日本の実際の給与明細は、標準報酬月額、賞与、扶養状況、加入する健康保険、自治体、住民税の年度などによって変わります。そのため、このアプリの金額は給与明細の再現ではなく、都市比較のための目安です。

オーストラリアのSuper guaranteeは雇用主から別途積み立てられるため、手取りからは差し引いていません。

米国の医療保険は勤務先や加入プランで大きく変わるため、KFFの雇用主提供保険調査による加入者平均を推定値として表示しています。フランスとメキシコの社会保険も、制度上の細かな条件が多いため、公式資料をもとにした比較用の近似値です。

## 起動と公開

Node.js（JavaScriptを動かすための実行環境）22.13以上を用意し、依存ファイルをインストールしてから開発用サーバーを起動します。公開時はVercelでこのプロジェクトを読み込み、ビルド設定はプロジェクトの設定を使用してください。

## 注意

このプロジェクトには、比較用に公的資料を参照した値と、地域統計をもとにした推定値が混在しています。画面上でも、公式値・自動取得値・推定値を区別して表示しています。
